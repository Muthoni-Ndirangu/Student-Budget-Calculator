Student Budget & Savings Calculator

About the Project

The Student Budget & Savings Calculator is a Python application designed to help students manage their pocket money, track expenses, and understand their saving habits.

Features

Accepts the user's pocket money.

Records expenses in different categories:

Food

Shopping

Transport

Other expenses

Calculates total expenses.

Calculates the remaining balance.

Identifies overspending.

Calculates spending and savings percentages.

Allows users to set a savings goal.

Provides spending warnings and feedback.

Validates user input.

Technologies Used

Python 3

How to Run

Install Python 3.

Download or clone this repository.

Open the project in a Python editor.

Run student_calculator.py.
